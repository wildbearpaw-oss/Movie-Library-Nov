# Movie Library — Личная кинотека

**Автор:** Новиков Александр
**Дата создания:** май 2026г

## Описание

Приложение для управления личной коллекцией фильмов с графическим интерфейсом. Позволяет добавлять, удалять, фильтровать и просматривать фильмы с сохранением данных в JSON‑формате.

## Возможности программы

* **Добавление фильмов:** ввод названия, жанра, года выпуска (1900–2026) и рейтинга (0–10).
* **Валидация ввода:** автоматическая проверка корректности данных.
* **Фильтрация:**
  * по жанру (частичное совпадение, регистронезависимо);
  * по году выпуска (точный год).
* **Удаление фильмов:** выбор из таблицы и удаление с подтверждением.
* **Сохранение данных:** автоматическое сохранение в файл `movies.json`.
* **Загрузка данных:** при запуске приложение загружает сохранённые фильмы.
* **Удобный интерфейс:** таблица с прокруткой и информативные сообщения.
* 
### Проверка корректности ввода

1. **Название** — обязательное поле. Если пусто, выводится предупреждение «Введите название фильма!».
2. **Жанр** — обязательное поле. Если пусто, выводится предупреждение «Введите жанр фильма!».
3. **Год** — должен быть целым числом в диапазоне 1900–2026. В противном случае выводится предупреждение «Год должен быть числом от 1900 до 2026!».
4. **Рейтинг** — должен быть числом (целым или дробным) в диапазоне 0–10. В противном случае выводится предупреждение «Рейтинг должен быть числом от 0 до 10!».

## Инструкция по запуску

### Требования
* Python 3.6 или выше.
* Стандартные библиотеки: `tkinter`, `json`, `os`.

### Шаги по запуску
1. Сохраните файл ***.py в любую папку
2. Откройте терминал/командную строку
3. Перейдите в папку с программой:
    `cd путь_к_папке`
